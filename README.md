# CodeAlpha_DiseasePredictionFromMedicalData
Disease Prediction Model

# Project Title
Disease Prediction from Synthetic Medical Data

# Objective

Predict whether a patient is likely to have a disease using medical and lifestyle factors.

# Features Used
* Age<br>
* Gender<br>
* Systolic Blood Pressure<br>
* Cholesterol<br>
* Blood Sugar<br>
* BMI<br>
* Smoking Status<br>
* Exercise Hours<br>
* Family History<br>

# Algorithms Used
* Logistic Regression<br>
* Support Vector Machine (SVM)<br>
* Random Forest Classifier<br>
