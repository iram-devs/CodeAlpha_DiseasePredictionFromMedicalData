# CodeAlpha_DiseasePredictionFromMedicalData
Disease Prediction Model

# Project Title
Disease Prediction from Synthetic Medical Data

# Objective

Predict whether a patient is likely to have a disease using medical and lifestyle factors.

#Features Used
Age
Gender
Systolic Blood Pressure
Cholesterol
Blood Sugar
BMI
Smoking Status
Exercise Hours
Family History
Algorithms Used
Logistic Regression
Support Vector Machine (SVM)
Random Forest Classifier
